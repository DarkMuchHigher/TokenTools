## [0.2.4] - 2026-10-13

### Добавлено

- Имя контейнера берётся из сертификата владельца: CN читается из `header.key` и показывается
  первой строкой на вкладках «Токен» и «Хранилище» и в `tokentools storage`, а техническое имя
  из `name.key` остаётся строкой ниже. Установка в `uMy` для этого не нужна.
- GUI, «Хранилище»: виден каталог ключей КриптоПро, а кнопка «Подробнее» показывает адрес
  контейнера в КриптоПро, папку, дату изменения каталога, размеры файлов, данные сертификата
  владельца, число сертификатов УЦ и готовую команду проверки. Пустой список ведёт на вкладку
  «Контейнер».
- GUI, «Журнал»: фильтр «только ошибки / основное / всё с трассой», счётчик записей и ошибок,
  расшифровка пометок.
- `tokentools storage`: печатает папку, издателя, сроки, серийный номер, SHA-1 и число УЦ.
- Раздел «Назначение и правовая информация»: проект помечен как учебный, описаны ограничения
  и ответственность пользователя.
- В LICENSE добавлена оговорка про назначение проекта и сторонние компоненты.

### Изменено

- Каталог контейнера в хранилище собирается из CN сертификата владельца: кириллица
  транслитерируется, служебные формы («ООО», «АО», «LLC») отбрасываются, результат обрезается
  до 8 символов, поэтому `ООО "ПИТЕРСТРОЙ"` даёт каталог `piterstr.000`. Без сертификата берётся
  имя из `name.key`, а если и его нет — случайное `t….000`.
- GUI: вывод `csptest` и `certmgr` отнесён к трассе и по умолчанию скрыт; время в журнале
  помечено как UTC; пометки уровней читаются словами (`инфо`, `ок`, `ошибка`, `трасса`).
- GUI: журнал обрезается пачкой (до 2000 записей при превышении 2500), а не на каждой записи.
- Из описания APDU убрана ссылка на разбор сторонней библиотеки.
- Сторонние бинарники больше не публикуются (`.gitignore`, `AGENTS.md`).

### Убрано

- `rutoken-fs`: неиспользуемые `read_file` и обход дерева файловой системы (`walk`, `walk_into`,
  `enum_current`, `enum_first`, `enum_next`, `select_parent`, `label`).
- `certfix`: поиск `p12utility.win32.exe` в `~/wine-test` — путь из отладочной сборки; проверка
  «успешно» по сырым байтам, дублирующая разбор вывода.
- GUI: неиспользуемое поле `has_keys_dir`.

### Исправлено

- Установка контейнера с уже занятым именем останавливается и показывает, где лежит существующий:
  КриптоПро не различает два контейнера с одним именем из `name.key`.
- GUI, «Хранилище»: сертификат привязывается к контейнеру по имени его папки. Раньше строка
  «Контейнер» из `certmgr` сравнивалась подстрокой, и при повторяющихся именах один сертификат
  показывался у нескольких контейнеров.
- Windows: внешние утилиты (`p12utility`, `csptest`, `certmgr`) запускаются без мигающего консольного окна.
- Windows: пути контейнера и сертификата передаются утилитам без префикса `\\?\`.
- Windows: выбор папки в GUI показывает список дисков и позволяет подняться выше корня диска.
- GUI: пока токен не найден, опрос считывателей идёт по таймеру, а не только при движении мыши.

## [0.2.3] - 2026-10-12

### Добавлено

- CLI: команда `repair` — переименовывает каталоги контейнеров в хранилище CSP, которые КриптоПро
  не видит (длиннее 8 символов или с не-ASCII именем).
- GUI: на странице «Хранилище» видно, какой сертификат из `uMy` привязан к контейнеру.

### Изменено

- Установка контейнера: каталог в хранилище CSP теперь короткий (≤ 8 ASCII-символов, при
  необходимости `t…`.000), полное имя записывается в `name.key`.
- `--link`: сертификат владельца извлекается из `header.key` и привязывается к ключу через
  `certmgr` (хранилище `uMy`) вместо `cryptcp -cspcert`.
- `storage` и `unmount` определяют имя контейнера по `name.key`, а не по имени каталога.
- GUI: страница «Установленные» переименована в «Хранилище»; списки переверстаны — усечение
  с подсказками, группировка контейнеров по считывателям, кнопки справа.
- Имя контейнера из `name.key` читается один раз при сканировании — GUI больше не обращается
  к файлу на каждом кадре.

### Исправлено

- `repair` теперь переименовывает и каталоги с не-ASCII именем короче 8 байт: раньше они
  пропускались, хотя `deploy` такие имена не создаёт.
- GUI: убрана неформатированная строка, ломавшая `cargo fmt --check`.

## [0.2.2] - 2026-10-09

### Изменено

- Переработан GUI; контейнеры устанавливаются туда, где их видит КриптоПро.

## [0.2.1] - 2026-10-09

### Исправлено

- Экспорты PC/SC для Windows, отказ от слепой подстановки PIN, ужесточена проверка файлов
  контейнера.
- GUI-подсистема Windows и путь к журналу.

### Изменено

- Журнал стал техническим, вендорские хардкоды убраны из пользовательских текстов.

## [0.2.0] - 2026-10-09

### Добавлено

- PIN-аутентификация Рутокена при выгрузке контейнеров.
- Разбор сертификата владельца и цепочки УЦ, просмотр хранилища `uMy`.

### Изменено

- Отказ от внешних зависимостей: собственный разбор аргументов CLI и загрузчик библиотек.

## [0.1.0] - 2026-10-09

### Добавлено

- Первый выпуск: CLI и GUI, выгрузка контейнеров с токена, снятие неэкспортируемости через
  `p12utility`, сборки для Linux и Windows.
